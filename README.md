# Points Rush Backend

Backend system for the Points Rush game.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Set up `.env` file from `.env.example`.

3. Run the app:

```bash
node server.js
```

## Push to GitHub

```bash
git init
git remote add origin https://github.com/mayoaiagent/points-rush.git
git add .
git commit -m "Initial commit"
git push -u origin main
```
